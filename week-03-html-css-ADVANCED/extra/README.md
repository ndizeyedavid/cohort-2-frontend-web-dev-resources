# Practice Projects

Three complete projects that combine the week's concepts. Each solves a layout problem a different way, which is the point of studying all three.

## Files

| File | Purpose |
|------|---------|
| [`crate-digging`](crate-digging) | A record store shelf built with Flexbox wrapping and no media queries. |
| [`the-kigali-review`](the-kigali-review) | A newspaper layout built with named Grid areas. |
| [`late-night-menu`](late-night-menu) | A diner menu using pseudo-elements, transitions, and a neon flicker. |

## Key concepts

- Choosing a layout system to match the problem
- Reading another student's CSS to learn a new technique

## How to run

Open `index.html` in a browser. No build step and no internet connection required.

## Try this

Open all three and resize the window. Each responds differently, and each uses a different layout system on purpose.
