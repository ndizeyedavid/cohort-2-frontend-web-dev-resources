# Semantic HTML

A landing page that uses meaningful tags instead of generic `<div>` wrappers. It looks the same either way, but the structure carries information that browsers and assistive technology can use.

## Files

| File | Purpose |
|------|---------|
| `index.html` | A page built from `header`, `nav`, `main`, `section`, `blockquote`, and `footer`. |

## Key concepts

- Choosing `header`, `nav`, `main`, `section`, and `footer` for meaning
- Using `blockquote` to attribute a quotation
- Why only one `<main>` per page

## How to run

Open `index.html` in a browser. No build step and no internet connection required.

## Try this

Replace the semantic tags with plain `<div>` elements and compare. The rendering stays the same, which is the point: the value was in the meaning.
