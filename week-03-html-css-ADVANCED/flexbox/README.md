# Flexbox

Five layouts built on the main axis and cross axis. The wrapping cards are worth resizing the window to watch.

## Files

| File | Purpose |
|------|---------|
| `index.html` | Centering, three `justify-content` rows, three `align-items` rows, wrapping cards, and a navbar. |
| `main.css` | The Flexbox rules, including `flex: 1 1 160px` for the wrapping cards. |

## Key concepts

- The main axis is the direction set by `flex-direction`
- `justify-content` works on the main axis, `align-items` on the cross axis
- `flex-wrap: wrap` plus a flex basis to build a responsive row
- `margin-left: auto` to push a single item to the far end

## How to run

Open `index.html` in a browser. No build step and no internet connection required.

## Try this

Change `flex-direction` to `column` and watch the meaning of `justify-content` and `align-items` swap.
