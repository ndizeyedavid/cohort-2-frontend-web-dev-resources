# Transitions and Animations

Six motion demonstrations, from a simple hover transition to keyframe loops and a loading spinner.

## Files

| File | Purpose |
|------|---------|
| `index.html` | A hover button, a slide-in, a pulse, a bounce, a spinner, and a card lift. |
| `main.css` | Transition shorthands, `@keyframes` blocks, and a `prefers-reduced-motion` guard. |

## Key concepts

- Transitions animate a change between two states
- `@keyframes` define multi-step movement
- `animation` shorthand, including the `infinite` keyword
- Turning off infinite loops when a visitor requests reduced motion

## How to run

Open `index.html` in a browser. No build step and no internet connection required.

## Try this

Enable Reduce Motion in your operating system settings and reload. The pulse, bounce, and spinner should stop, while the layouts still work.
