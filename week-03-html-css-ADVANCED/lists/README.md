# Lists

Two short lists that make the difference between ordered and unordered content obvious.

## Files

| File | Purpose |
|------|---------|
| `index.html` | An ordered list of foods and an unordered list of games. |

## Key concepts

- `<ol>` when sequence matters and `<ul>` when it does not
- `<li>` as the only direct child of either list
- The `type` and `start` attributes on `<ol>`

## How to run

Open `index.html` in a browser. No build step and no internet connection required.

## Try this

Change the `<ol>` to a `<ul>` and watch the numbers become bullets, then try `type="A"` and `start="5"`.
