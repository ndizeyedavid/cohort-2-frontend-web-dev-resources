# Frontend Web Dev Class — Activity Resources

> **A class-wide learning companion for our web development course.**
> Supplementary material — not graded. Built to help every student see the correct way to complete in-class activities, understand the thinking behind them, and level up their skills.

**Created by the Class Representative.** If you're a student who wants to see how activities should look or learn a concept from a different angle, this repo is your go-to resource.

---

## How to Use This Repository

1. **Browse by week** — Each week folder contains all the activities, demos, and icebreakers covered in class.
2. **Open `README.md` inside each week folder** — It gives you a full breakdown of what's inside, what concepts each file covers, and hints for working through them.
3. **Compare your work** — After completing an activity on your own, check the corresponding folder to see the reference implementation.
4. **Stuck?** — Look for the **Hints & Tips** section in each week's README. It explains common pitfalls and how to think through the problem.

## Learning Philosophy

This repository is meant to **supplement** your learning, not replace it. Here's the recommended workflow:

1. **Try it first** — Attempt the activity on your own without looking at the reference files.
2. **Check your understanding** — Read the week README's explanations and hints.
3. **Compare** — Open the reference files and compare with your approach.
4. **Reflect** — Ask yourself: _"Why did they structure it this way? What would I do differently?"_

This is how you turn "I completed the activity" into "I _understand_ the concept."
