# Extras: HTML Tables

A bonus activity showing how to build a structured data table. The example is a recreation of the ALU bus timetable for Kigali.

## Files

| File | Purpose |
|------|---------|
| `Table.html` | A bordered table using `colspan` and a `<ul>` nested inside a `<td>`. |

## Key concepts

- The `<table>`, `<tr>`, and `<td>` structure
- `colspan` to make a cell span several columns
- Nesting lists and headings inside a cell

## How to run

Open `index.html` in a browser. No build step and no internet connection required.

## Try this

Change `colspan="2"` to `colspan="1"` and see how the layout breaks. That shows exactly what spanning does.
