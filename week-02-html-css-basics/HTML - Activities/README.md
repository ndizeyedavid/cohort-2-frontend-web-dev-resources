# HTML Activities

Two unstyled pages that show what HTML means before any CSS is added. The markup is the message: each tag tells the browser what the content is for.

## Files

| File | Purpose |
|------|---------|
| `Basic-html-structure.html` | The smallest valid HTML5 document. Copy this as the starting point for any new page. |
| `Basic-form.html` | An eight-field registration form built with labels, input types, and a select. |

## Key concepts

- `<!DOCTYPE html>`, `<head>`, `<body>` and why the viewport meta tag matters
- Pairing `<label for>` with `<input id>` so clicking the label focuses the field
- Choosing an input `type` so the browser gives the right keyboard and hints

## How to run

Open `index.html` in a browser. No build step and no internet connection required.

## Try this

Add a ninth field of your own. Give it a matching label and a sensible input type.
