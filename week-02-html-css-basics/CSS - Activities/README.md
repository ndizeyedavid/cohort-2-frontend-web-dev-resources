# CSS Activities

The same registration form as the HTML activity, now styled. Open both files side by side to see how much CSS changes without touching the content.

## Files

| File | Purpose |
|------|---------|
| `Designed-Form.html` | The form markup upgraded with wrapper elements that give CSS something to target. |
| `style.css` | Reset, CSS variables, two-column Grid, input states, and a mobile breakpoint. |

## Key concepts

- A `*` reset with `box-sizing: border-box`
- CSS custom properties such as `--primary` as a small design system
- `:hover`, `:focus`, and `:active` states
- Collapsing a two-column Grid to one column with a media query

## How to run

Open `index.html` in a browser. No build step and no internet connection required.

## Try this

Change the value of `--primary` in `:root` and watch every button update at once.
