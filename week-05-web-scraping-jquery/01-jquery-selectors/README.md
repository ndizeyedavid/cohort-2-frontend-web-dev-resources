# jQuery Selectors

A playground for the different ways to target elements. Click a selector and watch the matches light up.

## Files

| File | Purpose |
|------|---------|
| `index.html` | A course-card playground and a row of selector buttons. |
| `style.css` | Layout plus the highlight state applied to matches. |
| `01-selectors.js` | Selection by ID, class, attribute, nesting, and tag name. |

## Key concepts

- jQuery selectors are CSS selectors
- A selection is a collection, so check `.length`
- `.each()` loops over the matched elements
- Set a CSS variable on the root element rather than on every element

## How to run

Open `index.html` in a browser. No build step and no internet connection required.

## Try this

Open the console, click the nested selector button, and read what `console.log` prints for each matched card.
