# Shared jQuery Library

A local copy of jQuery 3.7.1 so every jQuery activity works without an internet connection.

## Files

| File | Purpose |
|------|---------|
| `jquery-3.7.1.min.js` | The library, referenced by every jQuery activity with a relative path. |

## Key concepts

- A local library keeps class material reliable
- The same version can also be loaded from a CDN when preferred

## How to run

No action needed. Each activity loads this file before its own script.

## Try this

Replace the local path with `https://code.jquery.com/jquery-3.7.1.min.js` in one activity and confirm it still works with a connection.
