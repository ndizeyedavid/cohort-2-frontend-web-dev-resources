# Blog Scraping Example

A complete extraction of the practice publication into structured records, with category counts and summary statistics.

## Files

| File | Purpose |
|------|---------|
| `scrape-blog.js` | Extracts twelve article records, then groups and summarises them. |

## Key concepts

- Finding repeating blocks, then reading fields from each
- Reading `data-*` attributes alongside visible text
- Turning raw strings into a useful object shape

## How to run

Run each file with Node from this folder.

## Try this

Change the script to print only the articles in the `Web Engineering` category, sorted by score.
