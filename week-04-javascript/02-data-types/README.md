# Variable Data Types

Every type you will meet in the course, plus the coercion and comparison rules that cause the most confusion.

## Files

| File | Purpose |
|------|---------|
| `01-primitive-types.js` | String, number, BigInt, boolean, undefined, null, and Symbol. |
| `02-reference-types.js` | Object, array, function, and how references are shared. |
| `03-typeof-and-checks.js` | A `typeof` cheat sheet and the correct way to test each type. |
| `04-coercion-and-equality.js` | Implicit and explicit conversion, and `==` against `===`. |
| `05-truthy-falsy-and-templates.js` | Every falsy value, and template literals for interpolation. |

## Key concepts

- Seven primitive types and three reference types
- `typeof null === 'object'` is a bug that was never fixed
- Prefer `===` so values are not silently converted
- Only six values are falsy

## How to run

Run each file with Node from this folder.

## Try this

Add `[]` and `{}` to the truthy list in file 05 and confirm that an empty array and an empty object are both truthy.
