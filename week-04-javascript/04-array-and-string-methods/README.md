# Array and String Methods

The array and string methods you will use most often, including the `slice` versus `splice` distinction that catches everyone.

## Files

| File | Purpose |
|------|---------|
| `01-arrays-adding-removing.js` | `push`, `pop`, `shift`, and `unshift`. |
| `02-arrays-slice-splice.js` | Copying with `slice` and mutating with `splice`. |
| `03-arrays-search-sort.js` | `indexOf`, `find`, `join`, `sort`, `concat`, and spread. |
| `04-strings.js` | `trim`, case, search, slicing, replacing, and padding. |

## Key concepts

- `sort()` without a compare function sorts text, not numbers
- `slice` is safe, `splice` changes the original array
- `replace` changes only the first match, `replaceAll` changes every one
- `padStart` is handy for formatting numbers like dates

## How to run

Run each file with Node from this folder.

## Try this

In file 03, sort `[30, 1, 100, 4, 200]` with and without a compare function and explain the difference.
