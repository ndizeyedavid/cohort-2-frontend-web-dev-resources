# Objects

Objects, how to read and change them, and the two features that save the most typing: destructuring and spread.

## Files

| File | Purpose |
|------|---------|
| `01-creating-and-accessing.js` | Literals, dot versus bracket access, adding, updating, and deleting. |
| `02-methods-and-this.js` | Methods, chaining with `return this`, and the arrow `this` trap. |
| `03-nested-objects.js` | Nesting, optional chaining, and `Object.keys`, `values`, and `entries`. |
| `04-destructuring-and-spread.js` | Renaming, defaults, nested patterns, and copying with spread. |
| `05-checks-and-example.js` | Testing for properties, and a worked student records example. |

## Key concepts

- Dot access for valid names, bracket access for everything else
- `this` is the object that called the method
- Optional chaining `?.` avoids errors on missing data
- Spread copies one level deep

## How to run

Run each file with Node from this folder.

## Try this

In file 04, merge two objects with spread, then change a nested property in the copy and check whether the original changed.
